- **Quality and creativity beat rigid rules.** If a rule would force a worse product or creative outcome, flag the conflict to **QAsupervisor** rather than blindly enforcing.
- **Cinema stills/films:** imaginary **rune-like** marks only on signs/props. Never real-language text.
- **New art:** Imagine image generation in the app's flat kids style. **No PIL placeholder art.** If Imagine is unavailable, tell Ash (`lmk`). - **Loadout:** whole **sprite swap** per paint color. Never runtime tint. Red is the pattern; green no-hat Imagine set is done. See `scripts/loadout-brush.md` and `scripts/crab-canon.md`.
- **PAT:** never put the GitHub PAT in chat, commits, or docs unless Ash says otherwise. The 2026-10-15 standing rule allows sharing it with bots when needed; this handover gives **location only** (section 9).
- Honesty: do not claim Publish / APK / zip / video updated unless verified. Do not ship fake APKs. Grown-up downloads stay off the toddler home screen.
